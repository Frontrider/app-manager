# App manager

A simple application to deploy software to the nodes running on your tailnet.

Intended to be as simple as I can make it, while still being powerful enough.



## Applications

Not everything is fully tested.
What works for sure:
- All file browsers
- "OBS bridge"
- Hytale
- Jellyfin
- Komga
- Mindustry
- Rqbit
- SyncThing
