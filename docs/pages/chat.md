# Chat

Under [communications](/category/communication) you can find an XMPP service. it has a webclient, and a backend service.
It will use your regular users, you can login with any locally registered users.

To connect to another device, share it with anywherelan. The two services will find each other, and you'll be able to see each other's "public" rooms.

You can invite users from other machines by using <remote user name><device name>.awl. Eg: user@friend.awl.
You need to rename the device from the default "local-host" to a unique name. If both devices have the same name it won't work.

Don't rename the device from your own side, it will redirect you incorrectly.
